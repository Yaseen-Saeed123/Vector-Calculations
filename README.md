# Vector-Calculations
This is a calculator designed for performing vector and analytical geometry calculations

# What the calculator can do for 2D vectors in form (x,y)
1. Norm
2. Add/ Subtract Vectors
3. Scalar multiplication
4. Dot multiplication
5. Cross multiplication
6. Midpoint
7. Distance
8. Slope Equation (y = mx + c)
9. General Equation form (ax + by + c = 0)
10. Division of Straight line by ratio
11. Slope
12. Perpendicular distance
13. Extract coefficients from general equation
